# ADR-MOB-005 — Agent and expediter workflow

Status: **PROPOSED** | Date: 2026-10-11 | Owner: Mobile & Offline

## Muammo
Agent and expediter workflow bo‘yicha ko‘p tenantli mobil ERP xavfsizligi va ishonchliligini ta’minlash.

## Variantlar
Online-only / drafts / offline queue.

## Tanlangan yechim (taklif)
Local route, visit, order, return, delivery and payment-evidence drafts; visible queue states.

## Sabab
Field usability.

## Xavflar
Rejected operations.

## Boshqa modullarga ta’siri
CRM, UX, Sales, Finance.

## Qaror chegarasi
APPROVED emas. Mavjud tasdiqlangan biznes qoidalarini o‘zgartirmaydi. Boshqa domenlar bilan kelishish kerak.
